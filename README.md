# TB Bisma
Aplikasi toko offline responsif untuk HP, tablet, dan komputer.

## Build APK di GitHub
1. Upload seluruh isi folder ini ke repository GitHub.
2. Buka tab **Actions**.
3. Pilih **Build APK TB Bisma** lalu **Run workflow**.
4. Setelah selesai, download artifact **TB-Bisma-APK**.

Data tersimpan lokal di perangkat. Gunakan menu Backup untuk menyimpan salinan data.
